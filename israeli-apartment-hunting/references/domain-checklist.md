## Out of scope (explicit)

Re-litigated 2026-10-01; each would be asked by some users but belongs elsewhere.

| Item | Rationale |
|------|-----------|
| Buying property, mortgages | Different workflow; excluded by the description |
| Commercial leases | Not residential; the Fair Rental chapter does not apply |
| Landlord's tax on rental income | A landlord concern, not a tenant's |
| Protected tenancy (dayarut mugenet, key money) | Rare for a new renter and excluded from the Fair Rental chapter; one line in the scope note only |
| War-damage compensation for contents (Property Tax Compensation Fund) | Not a rental-search question; route to a war-damage or insurance resource |
| Dira LeHaskir and public housing tracks | Eligibility programs with their own rules; mention only if the user asks |
| Exact arnona rates for every city | Published per municipality each year; the skill routes to the current order rather than hard-coding them. Tel Aviv 2026 is given as the worked example |
